핵심 형태는 다음과 같습니다.
Conv2D → Conv2D → MaxPooling2D → Dropout
맥스풀링은 공간 크기를 줄여 계산량과 파라미터 수를 감소시키고, 중요한 특징을 더 넓은 영역에서 추출하게 합니다. 일반적으로 Conv2D마다 넣기보다는 Conv2D 2~3개마다 한 번 넣습니다.
참고로 현재 코드의 주석에는 크기 계산 오류가 있습니다. padding을 지정하지 않으면 기본값은 valid이므로:
23x23 → 2x2 Conv → 22x22
22x22 → 2x2 Conv → 21x21
21x21 → 3x3 Conv → 19x19
19x19 → 5x5 Conv → 15x15
처럼 크기가 줄어듭니다. 위 예제처럼 padding="same"을 사용하면 풀링이 크기를 줄이는 역할을 명확하게 담당합니다. Dense(100, activation="softmax")의 출력 형태는 원하는 대로 (100,)입니다.

========================================================================================================================================================================
stride는 필터가 한 번 이동할 때 움직이는 칸 수입니다.
- stride=1: 한 칸씩 이동
- stride=2: 두 칸씩 이동
예를 들어 입력 크기가 32×32, 커널이 3×3, padding='valid'라면:
Conv2D(64, (3, 3), strides=1)
# 출력: 30×30×64

Conv2D(64, (3, 3), strides=2)
# 출력: 15×15×64
크기 공식은 다음과 같습니다.
출력 크기 = floor((입력 크기 - 커널 크기) / stride) + 1
차이는 다음과 같습니다.
항목	stride=1	stride=2
이동 간격	1칸	2칸
출력 크기	크게 유지	약 절반으로 감소
이미지 세부 정보	많이 보존	일부 손실
계산량	많음	적음
용도	특징을 자세히 추출	다운샘플링


맥스풀링에서는 보통 다음처럼 사용합니다.
MaxPooling2D(pool_size=(2, 2), strides=2)
2×2 영역에서 최댓값을 고르고 두 칸씩 이동하므로:
32×32 → 16×16
이 됩니다.
일반적으로 CNN에서는 Conv2D는 stride=1로 특징을 추출하고, MaxPooling2D(strides=2)로 크기를 줄입니다. Conv2D(strides=2)도 풀링처럼 다운샘플링할 수 있지만, 정보가 더 많이 손실될 수 있습니다.
