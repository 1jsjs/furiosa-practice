## 1. 시계열 데이터 자르기

```python
def split_x(dataset, size):
    aaa = []
    for i in range(len(dataset) - size + 1):
        aaa.append(dataset[i:i + size])
    return np.array(aaa)
```

기본 원리는 긴 시계열을 겹치는 window로 바꾸는 것이다.

```text
원본 1차원 데이터       (100,)
2개 feature로 reshape   (50, 2)
window 생성             (45, 6, 2)
x = window[:, :-1, :]   (45, 5, 2)
y = window[:, -1, 1]    (45,)
```

`x`는 과거 timestep과 feature를 입력으로 사용하고, `y`는 마지막 timestep의 목표 feature만 선택한다.

## 2. 여러 미래값 예측

`keras56_split3.py`에서는 과거 6개 값으로 다음 6개 값을 한 번에 예측한다.

```text
x: (89, 6, 1)
y: (89, 6)
출력: Dense(6)
```

입력값은 0~1로 나누고, 예측 결과는 다시 100을 곱해 원래 숫자 범위로 되돌린다. 목표는 `[101, 102, 103, 104, 105, 106]` 근사이며 loss 0.1 이하를 기준으로 삼았다.

## 3. `return_sequences=True`

- `return_sequences=False`: 마지막 timestep의 hidden state만 출력
  - 출력 shape 예: `(batch, units)`
- `return_sequences=True`: 모든 timestep의 hidden state를 출력
  - 출력 shape 예: `(batch, timestep, units)`

따라서 RNN/LSTM을 여러 층 연결할 때 앞쪽 recurrent layer는 다음 recurrent layer에 sequence 전체를 넘기기 위해 `return_sequences=True`가 필요하다.

## 4. `Flatten()` 비교

`keras57_01_return_sequence.py`와 `keras57_02_rnn_flatten.py`는 LSTM 층을 쌓은 뒤 출력 형태를 비교한 실습이다.

```text
LSTM(return_sequences=True) 출력: (batch, timestep, units)
Flatten 적용 후:              (batch, timestep × units)
Dense 연결 후:                (batch, 1)
```

기록된 loss 비교:

| 구조 | 기록된 loss |
|---|---:|
| LSTM 1층 | 782.10 |
| LSTM 2층 | 786.18 |
| LSTM 3층 | 805.10 |
| LSTM 7층 + Flatten | 799.72 |

층을 깊게 쌓는다고 loss가 자동으로 좋아지는 것은 아니다. 데이터가 작고 정규화가 부족한 경우에는 과적합·최적화 어려움·출력 shape 불일치 여부를 함께 확인해야 한다.

## 5. Jena 기후 데이터 실습

`keras58_kaggle_jena1.py`에서는 10분 간격 Jena 기후 데이터를 사용해 `wd (deg)`의 하루치 144개 값을 예측했다.

### 데이터 구성

- CSV에서 `wd (deg)`를 target으로 분리
- 입력 feature: 13개
- 하루: 10분 간격 144개 timestep
- 입력 `x`: `(420120, 144, 13)`
- target `y`: `(420120, 144)` → 학습 직전 `(420120, 144, 1)`
- `RobustScaler`로 입력과 target을 각각 스케일링
- `shuffle=False`로 시간 순서를 보존

### 모델·학습

```text
LSTM(32, return_sequences=True)
Dropout(0.2)
LSTM(16)
Dense(64, relu)
Dropout(0.2)
Dense(144)
```

- loss: `mse`
- optimizer: `Adam(learning_rate=0.003)`
- `EarlyStopping`, `ReduceLROnPlateau`, `ModelCheckpoint` 사용
- batch size: 2000

## 중요 체크리스트

- `return_sequences=True`이면 출력이 3차원이고, 다음 recurrent layer가 받을 수 있다.
- `return_sequences=False`이면 마지막 timestep만 남아 다음 Dense에 바로 연결하기 쉽다.
- `split_x()`의 window 길이와 `x`, `y`의 timestep을 먼저 계산한다.
- 다중 출력 회귀에서는 마지막 `Dense` 유닛 수가 target 벡터 길이와 같아야 한다.
- `x`와 `y`의 시간 위치가 한 칸 어긋나지 않았는지 확인한다.
- scaler는 train 기준으로 `fit`하고, 검증·테스트·예측 데이터에는 `transform`만 적용한다.
- R²가 음수이면 모델이 단순 평균 또는 기준선보다 못한 상태이므로 정확도 개선 전 데이터 분할과 기준선을 먼저 점검한다.
